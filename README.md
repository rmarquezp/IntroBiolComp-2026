Welcome! In this repository you will find all the materials needed for this course. Once you learn how, you will also use it to upload your work. 

## Before you begin
All you will need for this class is a laptop that connects to the internet. Before the first day of class, please make sure your laptop has a `UNIX` terminal available. If you use Linux or Mac OSX, this should be already installed. If you use Windows, you will need to install one. Below are instructions to find or install the terminal in each operating system.

### Linux
A UNIX terminal is already installed on Linux. On most distributions you can open open it by pressing `Ctrl+Alt+t`.

### OSX
A UNIX terminal is already installed on Macs. You can find it in the <i>Applications</i> within the <i>Utilities</i> folder. 

### Windows
There are many emulators of a UNIX shell for Windows. I recommend installing `GitBash`, which is part of `Git`, a version control software that we will be using throughout the course. You can find an installer [here](https://git-scm.com/install/windows). If possible use the latest installer. 

### Chrome
A UNIX terminal can be accessed on Chrome through its "Linux development environment", also known as Crostini. Crostini is usually not active by default. You can find instructions on how to do so [here](https://chromeos.dev/en/linux/setup).
