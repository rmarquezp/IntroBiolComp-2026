# Unix 1: Introduction

## 1. Hello World!

Today we will start using the UNIX \textit{command line}, often called a \textit{shell}. In brief terms, a command line is an interphase where you can type commands, often known as prompts, translates them for the computer, and then displays the result of the operation your commands asked for.

Lets begin with a simple example. On the terminal type:

``` bash
echo "Hello world"
```
